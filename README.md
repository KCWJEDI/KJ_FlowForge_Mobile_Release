# KJ FlowForge Mobile Release

이 저장소에는 **앱 소스 코드가 없습니다.** APK 는 **Releases** 탭에만 있습니다.
Code 탭에 파일이 거의 없는 것은 정상이며, 배포 파일은 Releases 자산으로 제공됩니다.

## 최신 버전

- **v0.1.1** — [KJ-FlowForge-Mobile-0.1.1.apk](https://github.com/KCWJEDI/KJ_FlowForge_Mobile_Release/releases/download/v0.1.1/KJ-FlowForge-Mobile-0.1.1.apk)

## 이전 버전

- v0.1.0 — [APK](https://github.com/KCWJEDI/KJ_FlowForge_Mobile_Release/releases/download/v0.1.0/KJ-FlowForge-Mobile-0.1.0.apk)

## 설치

1. 위 APK 를 내려받습니다.
2. Android 에서 "출처를 알 수 없는 앱" 설치를 허용합니다.
3. 앱을 열고 라이선스 키를 입력합니다.
4. Notion 통합 토큰을 저장하고 칸반 데이터베이스를 연결합니다.

## 업데이트

앱이 GitHub Releases API 로 최신 버전을 확인합니다. 새 버전이 있으면 상단 배너와
설정 → 앱 정보에 표시되며, **APK 내려받기**를 누르면 브라우저에서 설치 파일을
엽니다.

소스 코드는 비공개 저장소 `KCWJEDI/KJ_FlowForge_Mobile` 에 있습니다.
